  <name>Task 1: GlassButton microinteractions (scale + glow + haptic)</name>
  <files>
    lib/shared/widgets/glass_button.dart
  </files>
  <action>
    Convert GlassButton from StatelessWidget to StatefulWidget. Add:

    ```dart
    bool _isPressed = false;

    void _onTapDown(TapDownDetails _) {
      setState(() => _isPressed = true);
      HapticFeedback.mediumImpact();
    }

    void _onTapUp(TapUpDetails _) {
      setState(() => _isPressed = false);
    }

    void _onTapCancel() {
      setState(() => _isPressed = false);
    }
    ```

    Wrap the existing button Container in:
    ```dart
    GestureDetector(
      onTapDown: _onTapDown,
      onTapUp: _onTapUp,
      onTapCancel: _onTapCancel,
      onTap: widget.onPressed,
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 150),
        transform: Matrix4.identity()..scale(_isPressed ? 0.95 : 1.0),
        transformAlignment: Alignment.center,
        decoration: BoxDecoration(
          borderRadius: BorderRadius.circular(widget.borderRadius ?? 12),
          boxShadow: _isPressed
            ? [BoxShadow(
                color: const Color(0xFF00FF88).withValues(alpha: 0.6),
                blurRadius: 20,
                spreadRadius: 2,
              )]
            : [],
        ),
        child: existingButtonContent,
      ),
    )
    ```

    IMPORTANT: Remove the original GestureDetector or InkWell that was calling onPressed (to avoid double-tap). The outer GestureDetector above owns all tap handling.

    Keep loading state (CircularProgressIndicator) behavior unchanged — when `isLoading == true`, disable haptic and suppress press animation by keeping `_isPressed = false` in onTapDown.

    All three GlassButton variants (PrimaryGlassButton, SecondaryGlassButton, SuccessGlassButton) inherit this behavior automatically since they are factory constructors wrapping GlassButton.

    Verify existing GlassButton widget tests in `test/shared/widgets/glass_button_test.dart` still pass — DO NOT change the test file; if a test fails due to StatefulWidget wrapping, fix the widget to preserve the testable interface (text, callbacks, keys).
