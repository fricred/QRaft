<objective>
Wire the FCM message handlers so notifications work in all three app lifecycle states:
foreground (overlay), background (OS notification tap → navigate), and killed (cold-launch → navigate).

Purpose: Without this plan, FCM tokens are registered (plan 01) and messages may arrive but the
app silently drops them. This plan closes the loop for the user-visible notification experience.

Output:
- `FcmOverlayHandler` widget that intercepts `FirebaseMessaging.onMessage` and shows a
  `flutter_local_notifications` banner while the app is in the foreground
- `notificationHandlerProvider` Riverpod provider wiring all three FCM lifecycle callbacks
  and navigating to `OrderDetailScreen` when notification contains `order_id`
- `MainScaffold` updated to initialize the provider and wrap with `FcmOverlayHandler`
</objective>

Navigation architecture (from lib/main.dart + lib/core/services/deeplink_service.dart):
- App uses `MaterialApp` with `navigatorKey: appNavigatorKey`
- `appNavigatorKey` is a `GlobalKey<NavigatorState>` defined in `deeplink_service.dart`
- Navigate to order detail: `appNavigatorKey.currentState!.push(MaterialPageRoute(builder: (_) => OrderDetailScreen(orderId: orderId)))`

FCM message payload convention (set by send-fcm Edge Function in plan 04):
- `message.data['order_id']` — UUID of the affected order
- `message.data['order_number']` — human-readable order number (e.g. QRA-2026-000042)
- `message.notification.title` — pre-localized Spanish title
- `message.notification.body` — pre-localized Spanish body

flutter_local_notifications (installed in Phase 1 plan 04 as `^17.2.4`):
- Initialize once with `FlutterLocalNotificationsPlugin().initialize(InitializationSettings(...))`
- Show with `.show(id, title, body, NotificationDetails(...))`
- iOS: requires `DarwinInitializationSettings`; Android: requires `AndroidInitializationSettings`
- For Android 8+ (API 26+): must create notification channel before showing

Create `lib/features/notifications/presentation/providers/notification_providers.dart`:

```dart
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:qraft/core/services/deeplink_service.dart';
import 'package:qraft/features/orders/presentation/pages/order_detail_screen.dart';

/// Navigates to OrderDetailScreen for the given order ID.
/// Uses the global appNavigatorKey — safe to call from any context.
void _navigateToOrder(String orderId) {
  final nav = appNavigatorKey.currentState;
  if (nav == null) return;
  nav.push(MaterialPageRoute(
    builder: (_) => OrderDetailScreen(orderId: orderId),
  ));
}

/// Provider that wires all three FCM lifecycle callbacks.
/// Read this provider once on app startup (in MainScaffold.initState or
/// via ref.read in a startup effect) — side-effect provider.
final notificationHandlerProvider = Provider<void>((ref) {
  // 1. Background tap: app was in background, user tapped notification
  FirebaseMessaging.onMessageOpenedApp.listen((RemoteMessage message) {
    final orderId = message.data['order_id'] as String?;
    if (orderId != null) _navigateToOrder(orderId);
  });

  // 2. Cold-launch tap: handled asynchronously in _checkInitialMessage below.
  // Cannot be async here; call _checkInitialMessage separately after provider init.
});

/// Call once after notificationHandlerProvider is read.
/// Checks if the app was opened by tapping a killed-app notification.
Future<void> checkInitialFcmMessage() async {
  final initialMessage = await FirebaseMessaging.instance.getInitialMessage();
  if (initialMessage != null) {
    final orderId = initialMessage.data['order_id'] as String?;
    if (orderId != null) {
      // Delay one frame so Navigator is ready
      WidgetsBinding.instance.addPostFrameCallback((_) => _navigateToOrder(orderId));
    }
  }
}
```

Create `lib/features/notifications/presentation/widgets/fcm_overlay_handler.dart`:

```dart
import 'dart:async';
import 'package:firebase_messaging/firebase_messaging.dart';
import 'package:flutter/material.dart';
import 'package:flutter_local_notifications/flutter_local_notifications.dart';

/// Initializes flutter_local_notifications and shows a banner whenever a
/// FCM message arrives while the app is in the FOREGROUND.
///
/// Wrap the scaffold body with this widget once (in MainScaffold).
class FcmOverlayHandler extends StatefulWidget {
  final Widget child;
  const FcmOverlayHandler({super.key, required this.child});

  @override
  State<FcmOverlayHandler> createState() => _FcmOverlayHandlerState();
}

class _FcmOverlayHandlerState extends State<FcmOverlayHandler> {
  final FlutterLocalNotificationsPlugin _localNotifications =
      FlutterLocalNotificationsPlugin();
  StreamSubscription<RemoteMessage>? _sub;

  static const _androidChannelId = 'qraft_orders';
  static const _androidChannelName = 'Órdenes QRaft';

  @override
  void initState() {
    super.initState();
    _initLocalNotifications();
    _sub = FirebaseMessaging.onMessage.listen(_onForegroundMessage);
  }

  Future<void> _initLocalNotifications() async {
    const initSettings = InitializationSettings(
      android: AndroidInitializationSettings('@mipmap/ic_launcher'),
      iOS: DarwinInitializationSettings(
        requestAlertPermission: false, // FCM requestPermission already handles this
        requestBadgePermission: false,
        requestSoundPermission: false,
      ),
    );
    await _localNotifications.initialize(initSettings);

    // Android 8+ requires an explicit notification channel
    const channel = AndroidNotificationChannel(
      _androidChannelId,
      _androidChannelName,
      description: 'Actualizaciones de estado de órdenes QRaft',
      importance: Importance.high,
    );
    await _localNotifications
        .resolvePlatformSpecificImplementation<
            AndroidFlutterLocalNotificationsPlugin>()
        ?.createNotificationChannel(channel);
  }

  Future<void> _onForegroundMessage(RemoteMessage message) async {
    final notification = message.notification;
    if (notification == null) return;
    await _localNotifications.show(
      message.hashCode,
      notification.title,
      notification.body,
      NotificationDetails(
        android: AndroidNotificationDetails(
          _androidChannelId,
          _androidChannelName,
          importance: Importance.high,
          priority: Priority.high,
          icon: '@mipmap/ic_launcher',
        ),
        iOS: const DarwinNotificationDetails(
          presentAlert: true,
          presentBadge: true,
          presentSound: true,
        ),
      ),
    );
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) => widget.child;
}
```
