TABLE `user_fcm_tokens`:
```sql
CREATE TABLE IF NOT EXISTS user_fcm_tokens (
  id            UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       UUID        NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  token         TEXT        NOT NULL,
  platform      TEXT        NOT NULL CHECK (platform IN ('ios', 'android')),
  device_label  TEXT,
  last_seen_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE(user_id, token)
);
```

RLS for `user_fcm_tokens`:
- Enable RLS
- SELECT policy: `user_id = auth.uid()`
- INSERT policy: `user_id = auth.uid()`
- UPDATE policy: `user_id = auth.uid()` (for last_seen_at refresh)
- DELETE policy: `user_id = auth.uid()` (stale token cleanup)

TABLE `notifications`:
```sql
CREATE TABLE IF NOT EXISTS notifications (
  id          UUID        PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     UUID        NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  order_id    UUID        REFERENCES orders(id) ON DELETE SET NULL,
  kind        TEXT        NOT NULL,   -- 'payment_approved','order_received','order_engraving',
                                      --  'order_engraving_done','order_shipped','order_delivered'
  title_es    TEXT        NOT NULL,
  body_es     TEXT        NOT NULL,
  data        JSONB,                  -- {"order_id": "...", "order_number": "..."}
  fcm_state   TEXT        NOT NULL DEFAULT 'pending'
                          CHECK (fcm_state IN ('pending','sent','failed')),
  fcm_retries INT         NOT NULL DEFAULT 0,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  sent_at     TIMESTAMPTZ,
  read_at     TIMESTAMPTZ
);

CREATE INDEX IF NOT EXISTS idx_notifications_user_pending
  ON notifications(user_id, fcm_state, created_at)
  WHERE fcm_state = 'pending';

CREATE INDEX IF NOT EXISTS idx_notifications_order
  ON notifications(order_id);
```

RLS for `notifications`:
- Enable RLS
- SELECT policy: `user_id = auth.uid()` — user reads their own notifications
- No INSERT/UPDATE/DELETE for `authenticated` role — only service_role may write
  (send-fcm Edge Function uses service_role key)

```dart
/// Top-level background handler — must be a free function annotated with
/// @pragma so the Dart VM keeps it alive as an entry point.
/// RULE: No UI calls (no BuildContext, no Navigator) in this function.
@pragma('vm:entry-point')
Future<void> firebaseBackgroundMessageHandler(RemoteMessage message) async {
  // background processing — data is available in message.data
  // Phase 10 plan 03 adds foreground overlay; this handler covers killed/background.
}

/// Activates FCM, requests permission, registers the token in Supabase
/// `user_fcm_tokens`, and listens for token rotations.
///
/// Call [initialize] once after authentication is confirmed.
class FcmService {
  FcmService._();
  static final FcmService instance = FcmService._();

  final FirebaseMessaging _messaging = FirebaseMessaging.instance;

  /// Requests notification permission (iOS shows a dialog; Android ≥13 shows a dialog).
  /// Returns true if granted.
  Future<bool> requestPermission() async { ... }

  /// Registers or refreshes the FCM token in Supabase user_fcm_tokens.
  /// Gracefully no-ops if the user is not authenticated.
  Future<void> initialize() async {
    // 1. Request permission
    // 2. Get current token
    // 3. Upsert into user_fcm_tokens with platform + last_seen_at = NOW()
    // 4. Listen to onTokenRefresh and re-upsert on rotation
  }

  Future<void> _registerToken(String token) async {
    final userId = SupabaseService.client.auth.currentUser?.id;
    if (userId == null) return;
    await SupabaseService.client.from('user_fcm_tokens').upsert(
      {
        'user_id': userId,
        'token': token,
        'platform': Platform.isIOS ? 'ios' : 'android',
        'last_seen_at': DateTime.now().toUtc().toIso8601String(),
      },
      onConflict: 'user_id,token',
    );
  }
}

final fcmServiceProvider = Provider<FcmService>((ref) => FcmService.instance);
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Flutter app → Supabase user_fcm_tokens | Authenticated user upserts their own token; RLS enforces user_id = auth.uid() |
| send-fcm Edge Function → notifications | Only service_role key may INSERT/UPDATE notifications rows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Spoofing | user_fcm_tokens INSERT | mitigate | RLS INSERT policy requires user_id = auth.uid(); client cannot register token for another user |
| T-10-02 | Tampering | notifications table | mitigate | No INSERT/UPDATE policy for authenticated role; only service_role (Edge Function key) may write |
| T-10-03 | Information Disclosure | FCM token leaked in logs | mitigate | FcmService never logs the token string; only logs "token registered" without value |
| T-10-04 | Denial of Service | token spam — user registers thousands of tokens | mitigate | UNIQUE(user_id, token) prevents duplicates; upsert on conflict updates last_seen_at only; send-fcm plan 04 deletes tokens with fcm_state = 'failed' after 3 retries |
</threat_model>
