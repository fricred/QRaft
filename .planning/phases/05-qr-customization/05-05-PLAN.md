    Create `lib/features/qr_generator/domain/services/qr_bulk_import_service.dart`:

    ```dart
    import 'package:csv/csv.dart';

    class QrBulkImportException implements Exception {
      final String code;
      QrBulkImportException(this.code);
    }

    class BulkQrRow {
      final String name;
      final String type;
      final String content;
      const BulkQrRow({required this.name, required this.type, required this.content});
    }

    class QrBulkImportService {
      QrBulkImportService._();

      static const _maxBytes = 1024 * 1024;   // 1MB
      static const _maxRows = 500;
      static const _codec = CsvCodec(fieldDelimiter: ';');

      static List&lt;BulkQrRow&gt; parseCsv(String raw) {
        if (raw.length > _maxBytes) throw QrBulkImportException('file_too_large');

        final allRows = _codec.decoder.convert(raw);
        if (allRows.isEmpty) return [];

        // Count valid (non-empty) data rows for cap enforcement
        final dataRows = allRows.skip(1).toList();
        final nonEmptyCount = dataRows
            .where((r) => r.length >= 3 && r[0].toString().trim().isNotEmpty && r[2].toString().trim().isNotEmpty)
            .length;
        if (nonEmptyCount > _maxRows) throw QrBulkImportException('too_many_rows');

        return dataRows
            .where((r) => r.length >= 3)
            .map((r) => BulkQrRow(
                  name: r[0].toString().trim(),
                  type: r[1].toString().trim().toLowerCase(),
                  content: r[2].toString().trim(),
                ))
            .where((row) => row.name.isNotEmpty && row.content.isNotEmpty)
            .toList();
      }
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User CSV file → app | File content from device filesystem or clipboard; untrusted |
| CSV cell content → QR data | Cell content becomes QR code data; no server processing |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05-01 | Tampering | CSV formula injection (=CMD, +cmd) | accept | CSV content populates QR data only — rendered as QR code strings, not executed in spreadsheet context; low risk in this app |
| T-05-05-02 | Denial of Service | Oversized CSV file | mitigate | 1MB size check before parse (raw.length > 1024*1024 → throws file_too_large before CsvCodec runs) |
| T-05-05-03 | Denial of Service | Too many rows | mitigate | 500-row hard cap enforced in parseCsv() before building QRs; throws too_many_rows immediately |
| T-05-05-04 | Tampering | Template profile bypass via applyFullTemplate | accept | Templates are const domain objects defined in source — user cannot inject custom QrFullTemplate via UI; they select from kQrTemplates list |
</threat_model>
