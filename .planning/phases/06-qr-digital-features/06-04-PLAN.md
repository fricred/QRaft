<objective>
Implement QRD-03: home-screen widget that displays a pinned QR from the user's library. Uses home_widget 0.9.1 (the only new package added in Phase 6). `HomeWidget.renderFlutterWidget(PrettyQrView, ...)` renders the styled QR to a PNG — no native-side QR rendering. Because the iOS widget requires Apple Developer Portal App Group configuration and an Xcode Widget Extension target, this plan is `autonomous: false` and includes a blocking human checkpoint.

Purpose: Lets users pin their favorite QR to their phone home screen for instant access without opening the app.

```dart
import 'package:home_widget/home_widget.dart';

// iOS only — set before all operations:
await HomeWidget.setAppGroupId('group.io.gothcorp.qraft');

// Render a Flutter widget to PNG and store under a key:
await HomeWidget.renderFlutterWidget(
  PrettyQrView(...),           // any Flutter widget; no Image.asset — use canvas-only widgets
  key: 'qr_widget_image',      // stored under this key in shared UserDefaults/SharedPrefs
  logicalSize: const Size(300, 300),  // MUST be ≤300px — iOS widget memory limit ~30MB
);

// Save arbitrary data:
await HomeWidget.saveWidgetData<String>('qr_label', 'My QR');
await HomeWidget.saveWidgetData<int>('updated_at', DateTime.now().millisecondsSinceEpoch);

// Trigger native widget refresh:
await HomeWidget.updateWidget(
  iOSName: 'QRaftWidget',          // must match Widget `kind:` in Swift
  androidName: 'QrWidgetReceiver', // must match receiver class name
);
```

Android Glance widget pattern (verified from research):
```kotlin
class QrWidget : GlanceAppWidget() {
    override val stateDefinition = HomeWidgetGlanceStateDefinition()
    override suspend fun provideGlance(context: Context, id: GlanceId) {
        provideContent {
            val prefs = currentState<HomeWidgetGlanceState>().preferences
            val imagePath = prefs.getString("qr_widget_image", null)
            if (imagePath != null) {
                val bitmap = BitmapFactory.decodeFile(imagePath)
                Image(provider = ImageProvider(bitmap),
                      contentDescription = "QR Code",
                      modifier = GlanceModifier.fillMaxSize().padding(8.dp))
            } else {
                Text("Open QRaft to pin a QR")
            }
        }
    }
}
class QrWidgetReceiver : HomeWidgetGlanceWidgetReceiver<QrWidget>() {
    override val glanceAppWidget = QrWidget()
}
```

  ```dart
  class QrWidgetService {
    static const String _appGroupId = 'group.io.gothcorp.qraft';
    static const String _iOSWidgetName = 'QRaftWidget';
    static const String _androidWidgetName = 'QrWidgetReceiver';
    static const String _widgetImageKey = 'qr_widget_image';

    QrWidgetService._();

    static Future<void> pinQrToWidget(QRCodeEntity entity) async {
      final decoration = QrDecorationBuilder.buildDecoration(entity.customization);
      final qrImage = QrDecorationBuilder.buildQrImage(entity.data, entity.customization);

      await HomeWidget.setAppGroupId(_appGroupId);

      await HomeWidget.renderFlutterWidget(
        PrettyQrView(qrImage: qrImage, decoration: decoration),
        key: _widgetImageKey,
        logicalSize: const Size(300, 300),
      );

      await HomeWidget.saveWidgetData<String>('qr_label', entity.data.length > 40
          ? '\${entity.data.substring(0, 40)}…' : entity.data);
      await HomeWidget.saveWidgetData<int>(
          'updated_at', DateTime.now().millisecondsSinceEpoch);

      await HomeWidget.updateWidget(
        iOSName: _iOSWidgetName,
        androidName: _androidWidgetName,
      );
    }
  }
  ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Flutter app → iOS UserDefaults (App Group) | PNG file path written to shared UserDefaults; only readable by apps in the same App Group |
| Flutter app → Android SharedPreferences | PNG file path stored; readable by widget within the same process context |
| Widget Extension → PNG file on disk | Widget reads PNG from app container shared storage; read-only access |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-13 | Information Disclosure | QR PNG in shared storage | accept | PNG is in the app's container (not world-readable); App Group restricts access to Runner + Widget Extension only |
| T-06-14 | Denial of Service | renderFlutterWidget memory | mitigate | logicalSize capped at Size(300,300) per research pitfall #2 — prevents EXC_RESOURCE memory crash on iOS widget |
| T-06-15 | Spoofing | Widget tap deep link | accept | Widget tap opens QRaft app (no URL parameter in v1); no injection surface |
| T-06-16 | Tampering | App Group ID mismatch | mitigate | App Group ID is a compile-time constant in both Dart ('group.io.gothcorp.qraft') and Swift — verified in checkpoint task 2 |
</threat_model>
