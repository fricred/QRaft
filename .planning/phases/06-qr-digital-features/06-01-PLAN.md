| Flutter client → ai-stylize Edge Function | User-supplied prompt + qr_url cross this boundary; must be sanitized server-side |
| ai-stylize Edge Function → Replicate API | API key must stay server-side; never reaches Flutter client |
| Replicate → Edge Function → Flutter | Image URL from Replicate is returned to client; client downloads from replicate.delivery CDN |
