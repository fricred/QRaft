  }) async { ... }

Edge Function invocation via supabase_flutter:
```dart
final response = await supabaseClient.functions.invoke(
  'ai-stylize',
  body: {'qr_url': qrStorageUrl, 'prompt': prompt},
);
// response.data is a Map; check response.status
// 200 = prediction created, data['id'] = predictionId
// 202 = still processing, call again with {'prediction_id': predictionId}
// 429 = monthly_limit_reached
// 500 = replicate_failed
```
