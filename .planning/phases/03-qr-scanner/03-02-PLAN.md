   await controller.stop();

   try {
     final BarcodeCapture? capture = await controller.analyzeImage(image.path);

     if (capture != null && capture.barcodes.isNotEmpty) {
       final rawValue = capture.barcodes.first.rawValue;
       if (rawValue != null && rawValue.isNotEmpty) {
         final scanResult = ScanResult.fromRawValue(rawValue);
         await SupabaseService.saveScanResult(scanResult);
         final updatedHistory = [scanResult, ...state.scanHistory];
         state = state.copyWith(
           lastScanResult: scanResult,
           scanHistory: updatedHistory,
           isLoading: false,
           error: null,
         );
         debugPrint('✅ Gallery scan result: ${scanResult.type} - ${scanResult.displayValue}');
       } else {
         state = state.copyWith(isLoading: false, error: 'noQRFoundInImage');
       }
     } else {
       state = state.copyWith(isLoading: false, error: 'noQRFoundInImage');
     }
   } on MobileScannerBarcodeException catch (e) {
     logDetailedError('Gallery analyzeImage', e);
     state = state.copyWith(isLoading: false);
   } finally {
     // Resume live camera stream regardless of outcome
     await controller.start();
   }

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gallery image → QR parser | User-supplied image; QR raw value is untrusted |
| vCard parsedData → Contacts API | Scanned vCard fields written to device contact store; could contain injected data |
| WiFi parsedData → Clipboard | SSID and password written to clipboard; password is PII |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-A | Tampering | vCard injection via crafted BEGIN:VCARD | mitigate | flutter_contacts only maps FN/TEL/EMAIL/ORG via _parseVCardData() — unknown fields are ignored; no arbitrary field injection into Contacts store |
| T-03-02-B | Info Disclosure | WiFi password saved in scan_history.parsed_data JSONB | accept | RLS on scan_history restricts to user_id = auth.uid(); user chose to scan the WiFi QR; acceptable in v1.0 — noted as future data minimization opportunity |
| T-03-02-C | Tampering | Malformed gallery image triggers analyzeImage crash | mitigate | MobileScannerBarcodeException catch block wraps analyzeImage; controller.start() is in finally block so camera always resumes |
| T-03-02-D | Spoofing | analyzeImage returns fake QR via manipulated image | accept | Same trust model as camera scan; user controls which image to pick |
| T-03-02-E | Info Disclosure | WiFi password visible on screen in _CredentialRow | accept | Only visible to the user who scanned the QR; password display intentional — obscured by bullet chars; copy is opt-in |
</threat_model>
